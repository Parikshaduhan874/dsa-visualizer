# DSA Visualizer

A small, dependency-free visualizer for classic algorithms. Open `index.html` in a browser; no build step.

## Algorithms
- **Sorting:** Bubble, Selection, Insertion, Quick
- **Searching:** Linear, Binary
- **Graph traversal (grid):** BFS, DFS

## Usage
Pick an algorithm, adjust size and speed, then press **Start**. On the grid, click or drag to draw walls before starting.

## Run locally
```
git clone https://github.com/<Parikshaduhan874>/dsa-visualizer.git
cd dsa-visualizer
open index.html
```
